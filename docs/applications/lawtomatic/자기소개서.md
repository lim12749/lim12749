# 임기원 자기소개서 · 로토매틱 지원

직접 만든 서비스를 사용자에게 출시하고, 실제 반응을 보며 개선하는 개발자 임기원입니다. 현재 가장 집중하고 있는 프로젝트는 AI 사주 콘텐츠 서비스 사주톡입니다. 로토매틱에 지원한 이유는 사주톡을 만들며 쌓은 웹서비스 개발·운영 경험과 AI 코딩 도구 활용 방식을, 법률 실무자의 반복 업무를 줄이는 제품에 적용하고 싶기 때문입니다. 로토매틱이 풀고 있는 자료 수집·확인·전달의 문제를 이해하고, 사용자가 실제 업무에서 쓰는 기능으로 완성하는 데 기여하고 싶습니다.

사주톡은 기획부터 개발·출시·운영까지 직접 맡은 개인 서비스입니다. Next.js·React·TypeScript를 기반으로 무료 체험, 인증, 결제, 유료 콘텐츠 열람까지 전체 흐름을 구현했습니다. 8월 21일 정식 출시 후 약 3주 만에 일 방문자 약 50명 규모로 운영하고 있으며, 무료 콘텐츠를 11종으로 확장했습니다. 캐릭터 결과와 유형 비교, 공유 카드, 내 수집품 기능을 추가하며 사용자가 콘텐츠를 경험하고 다시 찾아올 이유를 만드는 데 집중하고 있습니다.

이 과정에서 Claude Code와 Codex를 실제 개발 도구로 함께 사용하고 있습니다. 해결할 문제와 완료 기준을 제가 정하고, 관련 코드와 오류 로그를 바탕으로 기능 구현과 수정을 진행한 뒤 실제 화면·테스트·빌드 결과를 확인합니다. 사주톡의 콘텐츠 확장, 사용자 여정·결제 퍼널 분석 도구 구현, 문답 자동 전환과 공유 링크 오류 수정도 이러한 개발 과정 속에서 진행했습니다. 혼자 기획·개발·운영을 맡는 환경에서 두 도구를 활용해 구현과 검증을 반복하고, 운영 중 발견한 문제를 다음 개선으로 연결하고 있습니다. 최종 변경 사항과 사용자에게 미치는 영향은 직접 확인합니다.

출시 이후에는 기능을 더하는 것만큼 사용자가 어디에서 멈추는지 확인하는 일을 중요하게 보고 있습니다. 사주톡에 단계별 사용자 여정과 결제 퍼널을 분석하는 도구를 구현하고, 관리자·테스트 계정을 제외해 운영 데이터를 구분했습니다. 실제 피드백을 바탕으로 문답 전환을 개선하고, 공유 링크 오류를 수정했으며, 개인 방문자와 공유로 들어온 방문자에게 맞춰 행동 버튼을 다듬었습니다. 로토매틱에서도 법률 사무 담당자가 어느 단계에서 자료를 다시 찾거나 입력을 반복하는지 살피고, 실제 사용 흐름을 기준으로 개선점을 찾겠습니다.

AI 기능에서는 모델의 역할과 코드가 책임질 영역을 구분했습니다. 사주톡의 만세력 계산은 코드가 처리하고 모델에는 해석을 맡겼으며, 생성 결과에 정량 검수 게이트와 LLM 재검수·재생성 절차를 적용했습니다. 결제는 서버에서 가격과 상태를 검증하고 중복 이벤트를 처리했으며, 유료 콘텐츠는 주문 상태와 소유자를 확인한 뒤 열람하도록 구현했습니다. 이 경험을 바탕으로 로토매틱에서도 AI가 만든 초안과 확인된 데이터를 구분하고, 권한과 검토 절차를 갖춘 기능을 만드는 데 기여하고 싶습니다. 법률 자료의 정확성과 검토 기준은 실무 담당자 및 팀과 함께 정의하겠습니다.

AI가 따를 지침과 입출력을 구조화한 경험도 있습니다. 여행 사진으로 동선을 만드는 Codex 플러그인에서는 스킬 지침과 데이터를 분리하고 JSON Schema로 입출력 형식을 정했습니다. 공식 문서 조사와 정형 산출물 초안 작성에 AI를 활용하고, 실제 사진과 예외 입력으로 정보 누락·파일 형식 오류를 검증했습니다. 이러한 경험은 로토매틱이 찾는 스킬·개발 문서·컨텍스트 정리를 통한 업무 환경 개선과 연결된다고 생각합니다. 팀의 반복 작업 중 범위가 명확한 것부터 자동화하고, 다른 팀원도 재사용할 수 있도록 지침과 검증 절차를 정리하겠습니다.

사주톡 이전에도 현장의 업무를 소프트웨어로 옮기는 경험을 쌓았습니다. 가우스랩에서는 XR 점검·정비 관리 솔루션 MYVR의 메인 개발을 맡아 작업자의 업무 확인부터 관리자 보고까지 연결하고, XR에 익숙하지 않은 실무자를 위해 조작 흐름을 다듬었습니다. 별도 HoloLens 설비 점검 외주에서는 개발 리드가 DB를 구성하고, 저는 QR 인식·열상 데이터 표시·현장 점검 UI/UX를 맡아 협업했습니다. 에피젠의 헬스케어 플랫폼 개발에서는 검색 근거와 AI 해석을 분리하고 개인 데이터의 전달 범위를 제한하는 설계도 경험했습니다. 도메인은 달랐지만, 업무 절차를 이해하고 사용자와 역할에 맞게 기능을 만드는 방식은 같았습니다.

주요 웹 개발 경험은 Next.js와 Supabase 중심입니다. 로토매틱의 Spring Boot·JPA와 Python·LangGraph 환경은 기존 코드와 테스트, 팀의 리뷰를 통해 익히고 작은 기능부터 책임 범위를 넓히겠습니다. 함께 일한 팀 리드는 제 강점으로 먼저 시작하는 추진력과 조언을 행동으로 옮기는 태도를 꼽았습니다. 사주톡을 운영하며 익힌 실행과 개선의 습관을 바탕으로, 로토매틱에서도 동료와 방향을 맞추고 출시 이후까지 책임지는 개발자로 성장하겠습니다.
