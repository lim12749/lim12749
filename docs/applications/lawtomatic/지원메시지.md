# 로토매틱 지원 메시지

## 파프롬지니어스에 합류하고 싶은 이유

현장의 반복 업무를 줄이고, 사용자가 본업에 집중하도록 돕는 제품을 만들고 싶습니다. 가우스랩에서 현장 작업자와 관리자의 점검·보고 흐름을 연결하는 MYVR을 개발하며, 실제 업무 절차를 이해하는 것이 기능 구현만큼 중요하다는 것을 배웠습니다. 현재는 사주톡을 직접 출시·운영하면서 사용자 행동과 피드백을 바탕으로 서비스를 개선하고 있습니다. 이 경험을 법률 사무의 자료 수집·확인·전달 과정을 연결하는 로토매틱에 쏟고 싶습니다. 외주 납품을 넘어 하나의 제품을 팀과 오래 발전시키고 싶다는 마음도 큽니다. 모르는 것은 먼저 조사하고 질문하며, 작은 기능부터 믿고 맡길 수 있는 동료가 되겠습니다.

## 채용조건에 얼마나 적합한지

Next.js·React·TypeScript로 사주톡의 무료 체험부터 인증·결제·유료 콘텐츠 열람까지 직접 구현했습니다. 출시 후에는 사용자 여정·결제 퍼널 분석 도구를 만들고 운영 피드백을 반영하고 있습니다. Claude Code와 Codex를 기능 개발·오류 수정·검증에 함께 활용하며, Codex 플러그인의 스킬 지침과 JSON Schema를 설계한 경험도 있습니다. AI 계산·해석 분리와 생성 결과 검수 경험은 신뢰성이 필요한 서비스 개발에 연결할 수 있습니다. Spring Boot·JPA·LangGraph는 추가 학습이 필요하지만, 기존 코드와 테스트를 읽고 시니어의 리뷰를 반영하며 익히겠습니다. 먼저 실행하고 피드백을 실제 수정으로 옮기는 태도로 기여하겠습니다.
